## What This Deployment Means

Whakapapa deployment is about making the relational lane operational.

That includes:
- whakapapa search and recall
- connection and relationship visibility
- verification and review
- storage and handling that respects sensitivity and context

It is not only a UI problem and not only a database problem.

## Core Whakapapa Lane Needs

### Storage
- relational records must have a proper lane destination
- staging and trusted endpoint truth must remain distinct

### Guardian
- access and promotion must respect handling posture
- sensitive material must not be treated as generic open data

### Runtime Services
- search
- note-taking
- connection and lineage support
- verification and relationship-oriented retrieval

### Interaction
- users need ways to search, inspect, and extend relational understanding
- the exact interface can vary by profile

## Relational Truth And Review

Whakapapa work often contains:
- inherited knowledge
- conflicting accounts
- provisional connections
- high-context relational meaning

That means the system should preserve distinctions such as:
- source note
- summary
- inference
- reviewed relationship
- protected relationship data
