# Kitenga-te-Po Origin

Source provenance:
- copied from `kaitiaki-framework-legacy/archived/README.md`
- preserved here as lineage/origin memory for the canonical docs repo

## Overview

Kitenga-te-Po was framed as a kaupapa-driven artifact system guided by kaitiaki intelligence.

Useful enduring elements from the original origin text:
- strong kaupapa-first naming
- explicit kaitiaki identities
- tapu levels as handling posture
- kaupapa tags as thematic structure
- the idea that the system is a living awa of knowledge, not just document storage

## Original Core Principles And Structure

### Core Principle

**Awa Intelligence**:
- agents are not tools
- they walk beside us
- they do not lead from above

### Kaitiaki Named In The Origin

- **Kitenga**: The Carver, anchor and keeper of memory
- **Rongokarere**: Memory guardian coordinating Te Ao and Te Po
- **Tiwhanawhana**: Threaded memory weaver, ingests and shapes taonga
- **Ruru**: Distills knowledge into wisdom
- **Mataroa**: Creates embeddings and guides semantic search
- **Ghost_Wolf**: Echo, adapts, teaches, and audits
- **Aotahi**: Front-facing companion for paddlers

### Original Structural Pattern

The earlier origin document described a structure roughly like:
- `te_po/` for backend/runtime hull
- `supabase/` for database and migrations
- `frontend-aotahi/` for frontend
- `t_ao/` for console/ritual surface
- `docs/` for documentation
- `tests/` for test artifacts

That exact structure is not the canonical current contract, but it remains useful lineage memory.

### Original Tapu Levels

- `0 - Open`
- `1 - Whanau`
- `2 - Iwi`
- `3 - Sacred`

### Original Kaupapa Tags

- `whakapapa`
- `taiao`
- `tamariki`
- `mahi`
- `wai`
