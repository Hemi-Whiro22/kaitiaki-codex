# Lineage

This folder holds origin and lineage material for the canonical Kaitiaki documentation set.

Its purpose is to preserve:
- authorship and origin memory
- naming lineage
- original intent anchors
- early kaupapa framing that still matters

It does not exist to replace:
- current contracts
- operational guides
- deployment profiles

Use these files when you need to understand:
- where the system came from
- what meanings were attached to key names
- what should not be lost as the implementation evolves

Current lineage files:
- `KITENGA_METADATA.md`
- `KITENGA_TE_PO_ORIGIN.md`

Source provenance:
- copied from the legacy archive repo
- original files remain untouched there
