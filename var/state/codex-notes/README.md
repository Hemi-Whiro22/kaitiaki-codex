# Codex Notes Lane

This folder is for codex-only quality-of-life artifacts that help the co-dev workflow.

Examples:
- temporary recall notes
- phase summaries
- verification receipts
- helper output snapshots
- fixture references

Rules:
- this is not a project runtime folder
- this is not a substrate/database lane
- this should not become a hidden dependency for other services
- keep anything durable promoted into the right project docs or contracts
